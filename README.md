# Space Website

A personal project I built in my own time to practise the skills I learnt in university.

## Features
- A home page with a space-themed design 
- A page for each planet with an introduction, a facts table and a size comparison with the Sun
- Previous / Next / Home navigation between pages
- Hover effects on the planet images

## Built with
- HTML
- CSS (Flexbox, custom styling, image sizing with object-fit)

## What I learned
- Structuring a multi-page website and linking pages together
- Using one stylesheet across every page
- Debugging CSS: I traced a styling problem back to a single typo that stopped later rules from loading
